# v1.21 — 来访登记不再弹窗，整段交流放大到来访消息里

> **v1.22 追加**：桌面材料的未展开态已改为外形化（卡纸/账本/票据/信封），展开页字号与横线重排；本页的来访面板/拖放/回执逻辑不变。

这一版把来访从“左侧登记单弹窗”改成**一整块加大的来访消息面板**，所有内容都在里面：

- 来访者陈述、来意：上方的消息气泡；
- 拟办选项：消息下方的三行；
- 每个选项的后果：鼠标悬停时，在**面板左侧**出现自定义深色提示卡（不再用系统 tooltip）；
- 随附材料：从桌上/材料架拖进消息面板即可；底部出现材料 chip，点 `×` 取消；
- 回执、下一位/去排班：也在面板里，不再弹窗。

---

## 1. 布局

`VisitorChat`：**741×274**，位置 `(389, 96)`。

- 覆盖原来的学籍档案卡（389–676）和微信面板（689–1130），不动左侧项目书和右侧来访者肖像；
- 顶部 34px 标题栏：头像章、`来访消息`、第 N/位 · 角色、`精力/金钱`；
- 中间 94px 消息滚动区；
- 下方三条拟办行（26px/行）；
- 底部 36px 附件栏（拖放目标）；
- 回执状态把拟办区换成“下一位/去排班”大按钮。

因为不再有弹窗，来访时**档案卡/旧微信面板临时隐藏**，来访结束后恢复。

---

## 2. 选项后果的悬浮提示

- 选项行本身只显示 `批/驳/缓` 与来意，不塞效果文字；
- `mouse_entered` 时在**面板左侧**（覆盖项目书一侧，不挡选项）弹出 **320px 宽**深色提示卡：
  - `批` / `驳` / `缓` 色章 + 选项标题；
  - 金色细线；
  - `人情` 小节：角色名 + `+2` / `−1`，右对齐；
  - `收支` 小节：绩效、精力、金钱、声誉；
  - 有随附材料时增加 `随附` 小节；
  - `缓` 另列“临时通行条”；余额不足标红。
- 提示卡不接收鼠标，不会抢走 hover；移出选项即消失。
- 删除项目卡/材料卡/文件卡上的系统 tooltip，避免再出现系统灰框。

---

## 3. 拖材料提交 / × 取消

- `DeskItem` 增加 `drag_moved` / `drag_finished` 信号；拖动时把全局坐标交给 `AllocationView`。
- **整块来访消息面板都是投放区**；拖动中附件栏边框/底色变亮，显示“松开提交这份材料”。
- 松手后：
  - 材料卡回到原位；
  - 消息面板底部出现该材料的 chip：材料图标、纸样、`随决定提交`，右侧 `×`；
  - `visitor_item` 同步给 Main，选项结算时合并效果。
- 点 `×`：
  - chip 消失，`visitor_item=""`；
  - 再点选项就是不带附件的后果。
- 一次只有一份；再拖一份会替换。

---

## 4. 回执也在消息里

- 选完选项后，消息区清空并显示：
  - `来访回执 · 第 N/位`；
  - 来访者结局/回执正文；
  - 人情/收支摘要（`沈知夏 +2 · 学生 +2 · 精力 −1 · 声誉 −1`）；
  - 底部红色“下一位”或“去排班”按钮。
- 不再调用 `Modals.visitor` / `Modals.visitor_result`。
