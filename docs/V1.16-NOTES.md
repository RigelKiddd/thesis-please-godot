# v1.16 — 左键放入 / 右键取回、字体补齐与材料化弹框

这一版不改变审查规则、结局门槛和存档结构（仍是 **save v5**），只处理三件事：

1. 明日安排不再要求先点硬币；
2. 把旧字体子集里缺的字补齐；
3. 来访选项和已有弹框做成不同材质的纸面文件。

---

## 1. 明日安排：左键放，右键取

- **左键点项目框**：放入一枚该项目需要的硬币；框满了或预算不够时不放。
- **右键点项目框**：取回一枚；硬币没放完时“安排好了”仍然不可用。
- 左上角两枚大硬币和框里的小硬币只显示剩余/已放，**不再需要点击选中**；`1` / `2` 切换硬币的旧操作已移除。
- 底部提示改为：`左键放入 · 右键取回 · F 人情簿 · C 学院关系`。
- `--state=allocationcheck` 现在会用右键验证“取回”，并保留原来的预算/项目/来访断言。

涉及：`scripts/AllocationView.gd`、`scripts/InputRouter.gd`、`content/world.json` 的 `allocation.hint`、`tests/TestMain.gd`。

## 2. 字体：为什么有些字没有字/显示不对

旧版为了体积，把 Noto Sans SC、Noto Serif SC、ZCOOL、SimKai 都裁成了**只覆盖 v1.13 文本**的子集。v1.14/v1.15 新增的来访故事、学院名、导师名和 UI 文案里，有大量常用字不在子集内；Godot 只能走系统 fallback，于是出现缺字、字形突变或空白。

用 `fontTools` 扫了内容、脚本和场景里的全部 **1224 个 CJK 字符**，每个字体子集缺 **291 字**（SimKai 缺 272 字），包括：

`仁 函 岚 扶 栋 熄 瑾 砚 钱 销 韩 吴 郝 盏 键 灭 夜 攥 捏 躬 揣 摞 沓 稽 廉 洁 兜 蹭 喉 咙 …`

处理方式：

- 用系统里的 **NotoSansSC-VF / NotoSerifSC-VF** 生成 Sans/Serif 的 400/700 补字文件；
- 用 **SimKai** 生成楷体补字；
- 从 Google Fonts 下载**完整 ZCOOL QingKe HuangYou**，单独裁出像素风的补字文件 `FallbackPixel-400.ttf`，这样标题、访客名和硬币上的缺字仍然是同一套像素字形，不会突然变成黑体；
- `Ui.init()` 给 `F_UI` / `F_UI_BOLD` / `F_DOC` / `F_DOC_BOLD` / `F_HAND` / `F_PIXEL` / `F_PIXEL_TITLE` 都挂上对应 fallback；
- 复查结果：六组“主字体 + fallback”对 1224 个 CJK 字符的覆盖率都是 **0 uncovered**。

同时把几个在 34/30/18px 像素标题里最容易露出 fallback 的词换掉：

- `熄灯之前` → `灯灭之前`（“灭”已在像素补字里，风格统一）；
- `学生帮扶` → `学生资助`；
- `家里开销` → `家用`。

涉及：`assets/fonts/FallbackSans-*.ttf`、`FallbackSerif-*.ttf`、`FallbackKai-400.ttf`、`FallbackPixel-400.ttf`、`scripts/Ui.gd`、`content/world.json`。

## 3. 来访选项：来访登记与拟办单

原来的选项是三个大按钮；v1.16 改成一张真正的**来访登记与拟办单**：

```text
03 窗口 · 来访登记                         NO. 03-V01
来访登记 / VISITOR · 第 1 / 1 位              [来访 / 辅 / 待批]
沈知夏
来访人   沈知夏          单位/职务  学生工作办公室 · 辅导员
来访时间 21:10           接待窗口   03 号窗口 · 周明远
来访事由 九点四十，辅导员来敲门
■ 来访人陈述
  ……
■ 来意
  ……
■ 拟办意见
  □ [批] 先受理，材料后补   效果：沈知夏 +2 · 学生 +2 · 精力 −1 · 声誉 −1
  □ [驳] 按流程退回         效果：沈知夏 −1 · 吴敬之 +1 · 声誉 +1
  □ [缓] 开一张临时通行条   效果：沈知夏 +1 · 学生 +1 · 金钱 −1
经办：03 窗口 周明远                  归档：来访登记 · 2026.05.11
```

- 选项行本身可点：左侧空心方框、彩色“批/驳/缓”章、拟办文字、效果预览都在同一张表单上；
- 余额不足的行自动变灰、不可点；
- 结果页是同一套抬头/字段的**来访回执**，带“已批/已驳/已缓”章、办理结果、拟办行和归档号；
- 领导来访（郑国栋）同样走这张单，名字里的“栋”由像素补字兜住。

涉及：`scripts/Modals.gd` 的 `_visitor_header`、`_visitor_fields`、`_section_title`、`_visitor_option_row`、`_visitor_footer`、`visitor`、`visitor_result`。

## 4. 已有弹框：一套“材料皮肤”

`Modals._skin_card()` 给每个弹框换一张纸、一条色带、一个档案号，并保留原来的内容布局：

| 弹框 | 材质 | 色带 | 抬头 / 编号 |
|---|---|---|---|
| 标题 | 聘任档案 | 棕 | `03 窗口 · 聘任档案` / `NO. 03-00` |
| 每日通告 | 红头通知 | 红 | `03 窗口 · 每日通告` / `NO. 03-D01` |
| 操作说明 | 黄色便签 | 棕 | `03 窗口 · 操作说明` / `REF. 03-H` |
| 设置 | 蓝灰表单 | 蓝 | `03 窗口 · 设置` / `REF. 03-G` |
| 投诉单 | 红头表单 | 蓝红 | `03 窗口 · 投诉单` / `NO. 03-C` |
| 下班打卡 | 打卡单（虚线撕口） | 暗红 | `03 窗口 · 下班打卡` / `NO. 03-S01` |
| 停职 | 黑底通知 | 红 | `03 窗口 · 停职通知` / `NO. 03-X` |
| 结局 | 聘期审查档案 | 棕 | `03 窗口 · 聘期审查` / `FINAL. 03` |
| 人情簿 | 绿色账本 | 绿 | `03 窗口 · 人情簿` / `BOOK. 03-F` |
| 院系账本 | 绿色账本 | 绿 | `03 窗口 · 院系账本` / `BOOK. 03-C` |
| 来访 | 蓝灰表单 | 蓝 | `03 窗口 · 来访登记` / `NO. 03-V01` |

- 顶部统一有 **13px 档案条**：左侧材质色块 + 材料名，右侧文件号/归档号，下面一条同色细线；
- 底色/纹理：通知用亮纸、表单用蓝灰纸、账本用暖纸、档案用棕纸、打卡单用虚线撕口、便签用纯黄、停职用黑底；
- 纸张内容仍由原来的 `VBox` 排列，所以文本、按钮和数值卡片的层级不变；
- 弹框变高约 21px；长结局、院系账本、人情簿和来访单都已逐张截图确认不溢出。

### 顺手去掉的“滚轮翻页 N%”

材料窗口底部原来的 `滚轮翻页 0%` 浮层只是提示，实际滚动并不需要它；v1.16 把 `RequestDesk` 里的 `hint_plate` / `scroll_hint` 及百分比更新逻辑整段移除。长材料仍然可以直接滚轮翻页，只是不再有百分比角标。
