## 2. 输入路由

`scripts/InputRouter.gd` 定义唯一上下文：

```
TITLE / MODAL / REVIEW / ANNOTATION / NIGHT / GAMEOVER / ENDING
```

- `Main._input()` → `InputRouter.handle_mouse()`
- `Main._unhandled_input()` → `InputRouter.handle_unhandled()`
- 弹窗打开/关闭调用 `release_focus()`，避免 Enter 落到已释放/隐藏的按钮上。
- CHAT 是 REVIEW 的子模式：聊天按钮自己的 Control focus 消费 Enter；
  1/2/3、圈注、案卷仍然可用，不会出现“聊天抢圈注”。
- `ROUTERCHECK` 验证各状态的 context、modal 阻断、annotation 仍允许审查快捷键。

## 3. 原子存档 + 备份 + migrate

`GameState.gd`：

```
save.tmp  →  flush  →  save.bak（上一版）  →  save.json
```

- 先写 `save.tmp` 并 flush；
- 旧 `save.json` 复制为 `save.bak`；
- 再 `rename` 到 `save.json`；rename 失败则 copy 兜底；
- `read()` 先读 `save.json`，解析失败/非法版本自动回退 `save.bak`；
- `migrate()` 接受缺失 `version` 的 v1 存档，补齐 v2 统计字段；
- `clear()` 同时删除 `.json` / `.tmp` / `.bak`。

`BACKUPCHECK` 覆盖：备份回退、v1 迁移、恢复现场。

## 4. 文本完整性

`tools/check_text.py`：

- 严格 UTF-8 解码；
- 拒绝 UTF-8 BOM、U+FFFD、PUA 私用区；
- 拒绝 CP936 乱码特征（`锟斤拷`、`璁烘`、`瀹℃` 等）；
- 对 `Main.gd` 的中文字符串做语料抽样：`data.json` + 其他 `.gd` + README + 参考 HTML；
- `--strict` 把抽样警告升级为失败。

`tools/run_tests.ps1` 在 Python 可用时自动跑 `textcheck`；`tools/check_text.ps1` 是包装。

## 5. 案卷 / 证据面板

结论栏旁新增“案卷”按钮（快捷键 `C`）：

- 每个缺陷一行，三格：`圈`（圈注命中）、`问`（学生提示）、`看`（已翻到对应材料页）；
- 右上角印章显示证据因子 `3/3`、`2/6` 等，并标“已闭合 / 未闭合”；
- 无缺陷时显示“未发现条例问题，可直接通过”；
- 不评分、不替玩家下结论，只列已收集线索。

数据来自 `ann.all_marks()`、`chat.hint_group`、`viewed_tabs` 与 `GameData.source_tab()`。
`CASECHECK` 验证一行三格全亮、证据链闭合、弹窗打开。

## 6. 结案摘要

盖对后，如果本份材料有圈注、漏掉缺陷或证据链闭合，弹出 1.8 秒轻量卡：

- 命中 / 圈空 / 漏掉；
- 证据链完整/未闭合；
- 学生态度；
- “下一份”按钮，或自动推进。

自动流程（`autoday` / `autoweek`）设置 `skip_case_summary = true`，避免测试被 1.8 秒卡住。
`SUMMARYCHECK` 验证弹窗出现与“下一份”推进。
