# v1.12 — 夜班点击、桌面待办、字号、变体与指标

这一版处理两件事：把“夜班桌上文件只能按左右键”的输入 bug 修掉，并加入三类主角需要自己批准/退回的行政材料。

---

## 1. 夜班点击修复

### 根因

`InputRouter.handle_mouse()` 只放行 `REVIEW` / `ANNOTATION`：

```gdscript
if ctx != REVIEW and ctx != ANNOTATION:
    return
```

`NIGHT` 上下文直接返回，`Main._try_press()` 里本来存在的“文件标签 / 桌上文件卡”分支永远走不到。
键盘 `handle_unhandled()` 的 `←/→` 不受影响，所以表现成“只能左右查看”。

### 修复

- `handle_mouse()` 放行 `NIGHT`，与 `REVIEW` 共用 `_try_press()` / `_move_drag()` / `_end_drag()`。
- `_render_story_tabs()` / `_render_story_rail()` 的每个标签/卡片接 `gui_input` 作为兜底：
  左键按下直接 `_open_story_doc(i)`，避免被 ScrollContainer/父容器吞掉。
- `allows_mouse()` 同步包含 `NIGHT`。
- `nightclickcheck`：真实点击第 2 个标签 → doc 1，点击第 3 张文件卡 → doc 2，
  再按 `←` → doc 1。

## 2. 三类行政待办

### 位置与节奏

- 7 天共 9 份，每天 1–2 份；D4 / D7 各两份。
- **今日队列下面**是一叠纸：不同材质纹理、回形针、轻微旋转、层叠阴影；顶部显示“行政待办 N 份”。
- 点击纸堆把纸放到桌面，拖顶部“行政待办 · 拖动纸角”移动（`_try_press` 的 panel 拖动）。
- 当天结束前必须处理：`_end_day()` 检测 `pending_count()>0`，会打开第一份待办并阻止下班；处理完最后一份自动继续下班。
- 正确 +¥40，错误 −¥40，不扣声誉；待办进度按天重置（存档仍在当天早晨）。
- 批准/退回后纸张关闭（归档），播放盖章音效 + 墨章；不再是模态弹窗，聊天/桌面仍可见。

### 数据

`assets/requests.json`，由 `RequestData.gd` 加载，避免改原 `data.json`。

- 三种变体：奖学金 国家励志 / 国家 / 校级；优毕 院级 / 校级 / 省级；请假条 1 / 3 / 7 天。
- `applicantIndex` 指向当天队列学生，运行时填入姓名、学号、专业。
- 优毕的 `{{cover_title}}` / `{{dup_rate}}` 从该学生的论文数据取；`{{form_rate}}` = 查重率 + 5.6，用“推荐表与报告不一致”做退回理由。

| 天 | 材料 | 关键项 | 正确决定 |
|---|---|---|---|
| D1 | 请假条 1 天 | 手续齐全 | 批准 |
| D2 | 励志奖学金 | 缺 3 日班级公示 | 退回 |
| D3 | 国家奖学金 | 绩点/排名/公示/名额全过 | 批准 |
| D4 | 优毕院级 | 推荐表 18.2% vs 报告 12.6% | 退回 |
| D4 | 优毕校级 | 推荐表与报告一致 | 批准 |
| D5 | 校级奖学金 | 绩点 3.21 < 3.5 | 退回 |
| D6 | 请假条 3 天 | 手续齐全 | 批准 |
| D7 | 请假条 7 天 | 超 3 天且课程冲突 | 退回 |
| D7 | 优毕省级 | 学院排序 2/1，名额已满 | 退回 |

### 三种材质

| 材质 | 纹理 | 视觉 |
|---|---|---|
| 棉纸证书 | `paper_certificate.png` | 象牙白、金色边框、红色校印 |
| 牛皮卡纸 | `paper_cardstock.png` | 棕黄纤维、红棕抬头带、粗边框 |
| 蓝色复写纸 | `paper_carbonless.png` | 浅蓝横线、顶部撕口虚线、蓝色抬头 |

`tools/make_paper_textures.py` 用 Pillow 生成 256×256 可平铺纹理，不依赖外部素材。
`MaterialPaper.gd` 负责纹理/边框/抬头/字体；`RequestView.gd` 负责纸张布局与按钮。

### 代码接线

- `Main._build_desk()`：`request_btn` 夹板。
- `_begin_day()`：`requests.begin_day(day)`，当日有待办时 toast。
- `_open_request()` / `_on_request_action()`：打开、批准/退回、关闭。
- `_end_day()`：待办闸门；处理完最后一份后自动继续下班。
- `_state_dict()` / `Modals.shift()`：下班单显示“行政待办 1/1”。
- `_auto_resolve_requests()`：`autoday` / `autoweek` 自动按正确项处理。

## 4. 大字号模式

- `SettingsStore.text_scale`：1.0 / 1.15 / 1.25，独立于 `ui_scale`（窗口缩放）。
- `Ui.label` / `Ui.pixel` / `Ui.button` 统一按 `text_scale` 放大字号，并增加 `line_spacing`；按钮的最小高度也随字号增长。
- `Ui.set_font` 接管 `Docs` / `StoryDocs` / `Modals` / `Main` 里原先直接的 `add_theme_font_size_override`，让夜间文档、论文页、弹窗一起缩放。
- 设置里“字号”切换后调用 `Ui.apply_text_scale(self)`，遍历已有控件更新字号；不是重建场景。
- 1.25 不是完美的重排，固定位置的 HUD 仍可能偏紧；攻略建议长文界面优先 115%。
