# v1.26 — 修复开局公告按钮无法点击

## 问题

进入游戏后，标题纸窗/每日通告纸窗的按钮（“开始值班”“开始审查”“设置”）点不动，整张纸像被一层透明东西盖住。

## 根因

`PaperWindow._add_grip()` 把 `⋮` 把手作为子节点直接加到了弹窗卡片上：

- 标题/公告卡是 `PanelContainer`；
- `PanelContainer` 会把自己的子控件按内容区拉伸；
- 于是 20×22 的 `PaperGrip` 被拉成整张卡大小；
- 它 `mouse_filter = STOP`，位于按钮上方，吞掉了所有鼠标事件。

按钮本身、`_on_modal_action`、流程都没有问题；是把手控件把整张纸盖住了。

## 修复

- `PaperGrip` 不再挂到 `PanelContainer` 卡片上，而是挂到 **外层自由层**：
  - 普通模态：`modal_loose`；
  - 值班日志：`modal_top`；
- 把手保持 20×22，只占纸角；
- 用 `card.item_rect_changed` 同步把手位置，居中/拖动/吸附/位置恢复都跟随；
- 拖动时把手跟着纸走，不再参与卡片布局；
- 不会挡住“开始值班 / 开始审查 / 设置 / 关闭”等按钮。
