# v1.19 — 道具文件也做“材料”特质

> **v1.20 追加**：界面已去掉常驻操作提示与“今晚流程”，来访者换用手绘肖像登记照；材料化规则不变。

v1.18 把排班搬回主游戏版式后，桌上的 **明日安排 / 院系账本 / 临时通行条**（连同人情簿、感谢函）还是普通纸卡，和主游戏的补充材料架不是一套语言。v1.19 把它们统一成“材料”：

- 每份文件有 **纸样/材料**：`LEDGER` 账本、`SEALED` 密封、`CARDSTOCK` 卡纸、`CARBONLESS` 无碳、`MIMEO` 油印；
- 有 **材料图标**（`MaterialIcon` 线稿：账本、日历/安排、票据、信封）；
- 有 **材料编号**（M-01…M-05）和 **“材料”标签**；
- 有 **左侧材料色条**、纸样底色、材料类型小字；
- 桌面小卡、右侧“其他材料”目录、展开后的文件抬头三处统一。

---

## 1. 三种重点材料

| 文件 | 纸样 / 材料 | 图标 | 编号 | 色条 |
|---|---|---|---|---|
| 明日安排 | `CARDSTOCK / 卡纸` | 日历 + 时钟 | M-03 | 暗红 |
| 院系账本 | `SEALED / 密封` | 账本 | M-02 | 红章 |
| 临时通行条 | `CARBONLESS / 无碳` | 票据 | M-05 | 蓝 |
| 人情簿 | `LEDGER / 账本` | 账本 | M-01 | 绿 |
| 感谢函 | `SEALED / 封函` | 信封 | M-04 | 红章 |

- 数据只补 `style/icon/stock/stock_cn`；老存档没有这些字段时，`PropMaterial.traits(kind)` 按 `kind` 给默认值，不需要迁移。
- `RunState.base_items()`、感谢函、通行条的创建处都写入了这些字段。

---

## 2. 三处呈现

1. **桌面小卡**（136×70）：左侧 3px 材料色条 + 22×22 图标框；标题；`CARDSTOCK / 卡纸` 小字；M-03 编号；底部“材料”红边小签。
2. **右侧“其他材料”目录**（198×46）：按主游戏 `MaterialCard` 的横卡结构，纸样底色 + 4px 色条 + 27×30 图标 + 标题 + 材料类型 + 编号 + 材料签 + `›`；点击仍展开桌面文件。
3. **展开文件**（460×212）：抬头带材料色、18×18 图标、标题、材料类型、原 `sub`；正文纸样底色；左侧通高色条。

同时修了之前正文的对比度问题：人情簿/院系账本/明日安排的正文原来用浅色字写在浅色纸上，几乎看不清；现在统一改成深墨色（`#3a3020` / `#5a4a33` / `#6d5a3c`）。
