# v1.9 — 锚点、取舍、证据链、存档与可访问性

> **v1.11 已移除证据链与学生态度。** 本文第 3、4、5 节的相关描述仅作历史记录；
> 当前版本保留逐条锚点、三选一提示/省时、投诉单圈注回放和圈注准确率结局短评。

这一版把“区域级审查”推进到“条目级审查”，并把玩家做过的动作串成可以回放的证据。
结论逻辑仍然是确定性的：`GameData.audit()` 决定 expected，新增的只是**玩家如何看见、如何证明、如何被记住**。

---

## 1. 条目级锚点

缺陷现在带 `anchor` + `label`，圈注命中后显示具体问题，而不是组级标签。

| 页面 | 锚点 | 具体标签 |
|---|---|---|
| 封面 | `identity.name` / `identity.id` / `identity.major` / `identity.title` | 封面姓名不符 / 封面学号不符 / 封面专业不符 / 摘要题目不符 |
| 摘要 | `summary.chars` / `summary.keywords` | 摘要 468 字 / 关键词 2 个 |
| 查重 | `dup.identity` / `dup.rate` / `dup.seal` | 报告身份/编号异常 / 复制比 34.2% / 缺电子签章 |
| 参考文献 | `refs.header` / `refs.item.N` | 仅 12 篇参考文献 / 第 7 条：百度百科 |
| 正文 | `body.pages` / `body.gap` / `body.words` | 正文仅 16 页 / 缺第 13 页 / 正文 7,200 字 |
| 资格审查表 | `form.sig.advisor` / `form.sig.chair` / `form.sig.dean` / `form.ethics` | 缺导师签字 / 缺系主任签字 / 缺教学院长签字 / 缺伦理批件号 |
| 资格审查表 | `admin.credits` / `admin.tuition` | 学分 152/160 / 欠缴 ¥3,200 |

实现分两层：

1. `Docs.gd` 在渲染时给具体控件打 `set_meta("anchor", ...)`；
2. `AnnotationController.rect_for()` 优先用控件实际矩形（滚动、切页、字体变化都跟着走），
   取不到时才回退到 `AuditRegions` 的静态表。

参考文献每一条、三个签字格、伦理批号、学分、学费、页数徽章、字数徽章、缺页红格都是独立控件，
所以圈在列表任意一行不会再算命中整块区域。

`F9` 锚点调试框也改成“静态表 + 当前学生缺陷解析出的动态锚点”。

### “差一点”提示

圈空时不再直接淡出：

- 找最近的未命中锚点（56px 内）；
- 提示方向与具体标签，例如 `差一点：往左下再圈一点——缺导师签字`；
- 只给方向，不直接画框，不奖励。

同一份材料可以反复试，但每次只提示一次；圈注本身不扣分。

## 2. 微信回复：三选一的取舍

`ChatController.gd` 记录每名学生的回复状态。

| 选项 | 即时效果 | 代价 / 后续 |
|---|---|---|
| 按清单核对 | 学生信任 +1，后续回话更配合 | 不拿提示，证据链缺“学生提示” |
| 最担心哪项？ | 给出**最严重缺陷**的具体标签与组 | 每人只能问一次；后续回话更不安 |
| 先放桌上 | 省 10 分钟（`clock` 前移），学生不再补充 | 信任 −1，夜班邮件语气更冷 |

- “最担心哪项”用过一次后按钮显示“已问过”并禁用。
- 学生的第二句回话按选项不同；回复文案不再共用一套。
- 投诉单显示“学生态度：配合 / 冷淡 / 不安”。
- 夜班生成一封**下班后邮件**，引用白天学生说过的话；不同选项生成不同主题与正文。

## 3. 证据链

`StampController.evidence()` 把三件事对上：

1. 圈注命中了主缺陷所在组；
2. 微信里问出过同一组提示；
3. 打开过能佐证该组的材料页（封面/摘要/查重/参考文献/正文/资格审查表）。

三者齐备 → `chain=true`：

- 正确盖章额外 +¥40；
- 切到佐证页时提示“证据链完整”；
- 投诉单与结局显示 `圈注 + 学生提示 + X 已对上`；
- 结局统计“圈注命中 / 证据链次数”。

只圈不采信、只问不圈、或没翻到对应报告，都不算闭合。这样“问不问、圈不圈、翻不翻”才有组合意义。

## 4. 投诉单回放

`AnnotationController.attempts` 记录每一次落笔（命中与未命中、位置、标签）。

投诉单新增：

- 你的圈注回放：最多 3 条，命中 ✓ / 圈空 ✗；
- 学生态度；
- 证据链状态；
- 原有缺陷全文与绩效/声誉扣减。

未命中的圈也会被记录，因为投诉单回放的是“你做过什么”，不是“你成功过什么”。

## 5. 结局短评

`StampController.ending_note()` 根据以下数据生成 1–3 句短评：

- 圈注命中率 = hits / (hits + wrong + missed)
- 圈空次数
- 证据链完整次数
- “按清单核对”与“先放桌上”的次数对比

数据来自 `_record_evidence()`，在每次落章时累计；存档保留这些计数。

## 6. 每天自动存档

- 存档路径：`user://save.json`（Windows：`%APPDATA%\thesis_please\save.json`）。
- 时机：`_begin_day()` 开始时写一次；不存进行中的拖拽、聊天动画、圈注。
- 内容：天、学生索引（天开始为 0）、绩效、声誉、每日/累计计数、印章计数、夜班日志、证据链统计。
- 标题页检测到存档时显示“继续值班”，并提示存档日；读档回到**当天早晨**。
- 结局清档；“重新开始”清档；停职保留当天早晨存档，可重试。
- 设置单独存 `user://settings.cfg`，不随读档回滚。

`--state=savecheck` 验证读写与字段一致性；`--state=continuecheck` 验证读档回到当天 intro。

## 7. 可访问性

设置入口：标题页“设置”，或 HUD 右侧“设”，或 `G`。

| 选项 | 行为 |
|---|---|
| 界面缩放 100% / 125% / 150% | 调整窗口物理尺寸（canvas_items 等比缩放），不重排桌面；超出屏幕可用区域时自动回退 |
| 减少屏幕震动 / 闪光 | 关闭 `_shake()` 与全屏 `_flash()`，保留印章颜色、声音与冲击环 |
| 文字速度 慢 / 正常 / 快 | 同时影响学生陈述打字机与微信消息节奏 |
| 音效 开 / 关 | 与 `M` 键同步，写入设置 |
| 键盘 | 弹窗自动聚焦第一个按钮；Tab 移动；Enter / Space 激活；Esc 关闭帮助/设置；方向键翻材料；1/2/3 选印章 |
| 色盲 | 印章始终带“通过/修改/不通过”文字；不新增仅靠颜色区分的信息 |

焦点态使用金色描边（`Ui.button` 的 focus style），不再是无可见反馈的空样式。

## 8. 代码拆分

新增控制器（`preload` 引入，不依赖全局类缓存）：

| 文件 | 职责 |
|---|---|
| `GameState.gd` | 天/学生/绩效等流程快照、每日存档读写与恢复 |
| `AnnotationController.gd` | 锚点解析、命中、差一点、marks、撤销退款、attempt 回放 |
| `ChatController.gd` | 三选一策略、一次性提示、信任/省时、后续回话、夜班邮件 |
| `StampController.gd` | 结论评估、证据链、结局短评 |
| `NightController.gd` | 夜班附加文档与日志条目 |
| `SettingsStore.gd` | 设置持久化与窗口缩放 |
| `Main.gd` | 场景组装、绘制、输入分发、流程切换 |

**仍未完成**：UI 构建、拖拽与动画仍在 `Main.gd`。这一次只把**状态与判定**移出，
因为在不破坏近 5000 行 UI 代码的前提下，整块搬运的收益低于风险。下一步若要继续拆，
优先把 `_build_*` 与 `_input/_try_press/_move_drag/_end_drag` 分成 `DeskView.gd` 与 `DragController.gd`。

## 10. 已知限制

- `shotregress` 依赖本机渲染结果；不同 GPU/驱动/系统缩放会产生像素差，属于基线维护问题。
- 音乐只提供提示词，未内置音频；`Sfx.gd` 仍是程序合成音效。
- 存档不保存“当天进行到第几个学生”，按设计回到当天早晨；这是短流程游戏的取舍。
- `Main.gd` 仍是最大的文件；本次拆分以“判定与状态”为边界，UI 尚未完全迁出。
