# 大学材料样式库 / Material Catalogue

这页是“论文审批处”后续可继续扩的材料清单。`style` 列是当前游戏已支持的纸张；
未实现的条目保留为下一版候选。现有 13 种样式可以在编辑器“待办包 → 材料 → 纸张样式”里直接选。

## 视觉规则

- 证件类（学生证/身份证/护照）用冷色证件带 + 照片框 + 编号，不使用大面积金色。
- 证书类（奖学金/录取/毕业）用衬线标题、双线或信头、红色校印。
- 财务/成绩类用表格、横线、金额/绩点等指标，章压住数据边缘。
- 公示/通知类用油印灰黑，避免装饰边；请假/登记类用复写纸蓝线。
- 所有样式继续共用游戏的纸色、墨色与红章体系，不引入照片或高饱和渐变。

## 接入方式

1. 在 `MaterialPaper.gd` 增加 style 配色/纹理/ornament；
2. 在 `RequestDocs.gd` 增加对应顶部装饰（或复用已有 ornament）；
3. 在编辑器 `STYLE_DEFS` / `STYLE_ORDER` 注册，刷新纸张样式页；
4. 给新 style 写一份 `stylecheck` 样例，跑 `run_tests.ps1`。

> 条件链和材料库都先在编辑器里准备好；等规则稳定后，再把 `logic.json` 编译成运行时条件表，接入待办、夜班或分支剧情。
