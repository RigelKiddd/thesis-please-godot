# v1.22 — 未展开只给外形，展开才看细节

> **v1.23 追加**：来访登记改为纸质窗口（可拖动），不再使用仿微信面板；本页的材料外形/原木桌说明不变。

这一版把桌面材料的“未展开态”从迷你表单改成**有辨识度的材料外形**，并把展开后的字号、行距、横线重新对齐。

另外，**不再单独造一个桌子/文件夹**：材料直接散在主游戏原本的木桌上拖动，主游戏中央卷宗在排班期间隐藏，收工后恢复。

---

## 0. 文件回到原桌面

- 删除分配界面自己的“桌上文件 / DESK FILES”大文件夹和内部 `_desk` 桌面。
- `DeskItem` 直接挂在主游戏原木桌区域 `(268,375,760,396)`，没有额外底板、标题条或新桌子。
- 排班时用 `DeskView.set_allocation_chrome(true)` 临时隐藏主游戏中央卷宗；结束时恢复。
- 材料就散在木桌上，可自由拖动、点开、收起；不再有“文件夹桌面”这一层。

## 1. 未展开：只看外形和两个大字

- **明日安排**：卡纸日程片。右上切角、左边两个装订孔、顶部暗红压线、右下淡日期格；中间日历/时钟图标 + **「明日」**。
- **院系账本**：账本封面。左侧书脊、封面标签框、右侧松紧带与金属扣、右下小印；账本图标 + **「账本」**。
- **临时通行条**：票据。上下切角、左右半圆缺口、右侧虚线撕口和存根、顶部蓝线；票据图标 + **「通行」**。
- **人情簿**：深绿书脊的账本，**「人情」**。
- **感谢函**：信封。翻盖折线、火漆印、右上邮票框；信封图标 + **「感谢」**。

不再在小卡上写 `CARDSTOCK / 卡纸`、`M-03`、`材料`、`总 4`、`第 1 天` 等小字；这些都留给展开页。小卡只保留：外形 + 材料图标 + 两个大字。

右侧“其他材料”目录也同步减法：只剩纸样色条、图标、完整标题和 `›`，去掉了 6–7px 的材料类型/编号/材料签。

实现：新增 `scripts/MaterialShell.gd`，按 `shape` 绘制 schedule / book / ticket / envelope 四种轮廓与装饰；`DeskItem` 关闭自身的方框底与阴影，改为“壳 + 图标 + 大字”。
