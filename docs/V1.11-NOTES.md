# v1.11 — 精简：移除案卷 / 证据链 / 学生态度

按需求，这一版把 v1.10 的“案卷 / 证据链”和“学生态度”整体拿掉，回到更轻的结构。
三选一、逐条圈注、投诉单圈注回放、夜班来信都保留。

---

## 移除的内容

### 案卷 / 证据链

- 删除结论栏旁的“案卷”按钮、`C` 快捷键、`Modals.case_file()` 与 `_evidence_row/_evidence_chip`。
- 删除证据链计算与 `+¥40`：
  - `StampController.evidence()` / `chain_line()` / `_key()` / `_tab_name()`；
  - `Main` 的 `viewed_tabs`、`last_evidence`、`chain_count`；
  - 投诉单与结局里的证据链文案；
  - `evidcheck` / `casecheck` / `summarycheck` 三个测试状态。
- 保留：
  - 逐条锚点、具体标签、圈注 +¥20、差一点提示；
  - 投诉单的圈注回放（`AnnotationController.attempts`）；
  - 结局的“圈注命中”统计与按准确率给短评。

### 学生态度

- 删除 `ChatController.trust`、`attitude()`、`attitude_line()`。
- 删除投诉单“学生态度”、结局按“按清单/放桌上”给短评。
- 删除 `checklist_count / concern_count / desk_count` 与其存档字段。
- 三选一保留：
  - 按清单核对：不给提示；
  - 最担心哪项：给最严重缺陷的具体标签，每人一次；
  - 先放桌上：省 10 分钟、学生不再补充。
- 学生下一句、夜班来信仍按选项不同（这是对白/内容差异，不是态度数值）。

### 存档

- `GameState` 不再保存 `chain_count / checklist_count / concern_count / desk_count`。
- 旧存档由 `migrate()` 保留未知字段、忽略不再使用的键；读取不受影响。
