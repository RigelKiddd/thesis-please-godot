# v1.25 — 通用纸质窗口、值班日志、材料批注/归档、复访回执

在 v1.23 的字体与桌面基础上，补上四组长期系统：

1. **通用 PaperWindow**：设置、帮助、值班日志、回执/聘期审查等纸质弹窗统一具备拖动、边缘吸附、位置记忆、Esc 关闭；请求包/附件继续使用 `DesktopWindowManager`，并补上置顶压暗与松手吸附。
2. **值班日志 + 周报 + 多结局**：每次来访批办、排班完成都会写入日志；来访结束可打开纸质日志；第 7 天聘期审查附“七天人账”；结局按绩效/声誉/人情/学院关系分流。
3. **材料批注 / 盖章 / 归档**：展开材料底部有手写批注、已阅/缓办/驳回、归档/取回；归档进入“卷宗”模式，可从卷宗取回；批注会随笔材料进入来访登记单。
4. **复访与回执**：记录每个角色的上一次批办；再次来访时，登记单开头会带上次回执，角色会“带着上次的后果来”。

> v1.24 的全局宋体+Times 字体实验已撤回；当前仍使用 v1.23 的 ZCOOL / Noto Sans / Noto Serif / SimKai / Consola 混排。

## 1. PaperWindow

- 新增 `scripts/ui/PaperWindow.gd`：拖动、屏幕内约束、边缘吸附、静态位置记忆。
- `Main._show_modal()` 在原有 CenterContainer 布局上挂 `PaperWindow`：首次拖动时才把卡片移到 `modal_loose`，原有内容不动。
- 每张纸质弹窗左上角有 `⋮` 纸角把手；标题栏空白处也可拖。
- 拖动时纸窗轻微放大、阴影加深，松手吸附时用 0.12s 回弹；位置记忆在本次运行内。
- `_hide_modal()` / `_show_modal()` 清理 `modal_loose` 与 `modal_top`。
- 设置、帮助、账本、投诉、日志、结局都复用；`DesktopWindowManager` 增加 `snap_window()` 和置顶时其余窗口压暗。

## 2. 值班日志 / 周报 / 多结局

- `RunState.duty_log`：记录 `visitor`（谁、什么材料、批/驳/缓、结果、绩效、人情、随附材料）和 `projects`（项目数、绩效、声誉）。
- `RunState.visitor_history`：按角色记录上一次批办，供复访使用。
- 分配界面“值班日志”按钮 / `L` 键打开纸质日志；按天分组，最多显示最近 22 条。
- 日志是独立的 `DutyLogCard` 纸卡：红装订线、胶带、教务处红章、横线纸、按天分组的批办行；不是普通弹窗套壳。
- `_week_line()` 汇总七天：每天来访数、排班绩效、批办标签；写进聘期审查“七天人账”。
- `_rank()` 新增：停职调查、学院清算、人情网，再落到长聘/续聘/留用/解约。

## 3. 材料批注 / 盖章 / 归档

- `DeskItem` 扩为 `460×274`，底部工具条：
  - 手写批注 `LineEdit`（写入 `item.note`，随存档）；
  - 已阅 / 缓办 / 驳回（写入 `item.stamp`，并有一枚红章压纸的缩放/淡出效果）；
  - 归档 / 取回（写入 `item.archived`）。
- 分配界面新增“卷宗”模式：只显示已归档材料，可点“取回”放回桌面；右侧材料目录自动隐藏归档项。
- 排班完成时对一次账：人情簿总额与院系账本总额差 ≥5 时，生成“对账 / 两边对不上”的值班日志和警示 Toast。
- 来访登记单在随附材料有批注/盖章时显示“随附材料批注 / 上次手写”。

## 4. 复访

- 同一角色再次来访时，`_filled_visitor()` 读取 `visitor_history`，在陈述前插入：
  “上次（第 N 天）你批/驳/缓了「…」。这次他先把上次的回执放在桌角。”
- 现有重复角色：沈知夏（学生，第 2/6 天）、系主任（第 3/6 天）；
- 历史同时带上次随附材料的手写批注，供来访登记单显示。
