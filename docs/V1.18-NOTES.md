# v1.18 — 灯灭之前直接套用主游戏界面

> **v1.19 追加**：桌上的明日安排/院系账本/临时通行条等文件已材料化（纸样、材料图标、M 编号、材料签），见 `V1.19-NOTES.md`；本页的版式说明不变。

v1.17 做的是“上方排班板 + 下方新桌子”，理解错了。v1.18 改成 **直接复用主游戏窗口的版式**：

- 主游戏里 **审查条例** 的位置 → **明日安排项目簿**；
- 主游戏里 **学籍档案** 的位置 → **排班档案/预算卡**；
- 主游戏下面的 **卷宗纸张** → **桌上文件**（人情簿/院系账本/感谢函/通行条）；
- 主游戏右侧 **其他材料架** → **文件目录**；
- 主游戏右侧 **学生肖像** → **来访者肖像**；
- 主游戏右侧 **学生微信** → **来访者微信**；
- 主游戏左侧 **今日队列** → **今晚流程**；
- 主游戏底部 **印章台** → **排班提示条**。

窗口背景、木桌、HUD、纸张/档案卡/微信的形式都还是主游戏那一套。

---

## 1. 版式对齐

| 主游戏 | 灯灭之前 |
|---|---|
| 左上 `毕业论文审查条例` 书 | `明日安排` 项目书（8 项，2×4） |
| 中上 `学籍档案` 卡 | `排班档案 / ROSTER`（精力/金钱/已分配/预计） |
| 右上 `学生消息` 微信 | `来访消息`（来访者陈述、来意） |
| 最右学生肖像 | `VisitorPortrait` 来访者肖像 + 姓名牌 |
| 中间卷宗/纸张 | `桌上文件` 文件夹（道具纸卡） |
| 右侧 `其他材料` 架 | `其他材料` 文件目录（点击展开对应纸卡） |
| 左侧今日队列 | `今晚流程` 说明 |
| 底部印章台 | 排班提示条 |

- 项目书里每个项目是一个 150×45 的小纸卡：名称、硬币类型/上限、已排/上限、进度条；**左键放、右键取**；鼠标悬停显示原来的项目说明与效果。
- 排班档案卡：精力/金钱大字、已分配/来访开销、预计绩效、人情预览、`安排好了 · 进入第 N 天`。
- 标题旁仍保留“全部收回”。

涉及：`scripts/AllocationView.gd` 全部重排；`scripts/DeskItem.gd` 继续作为文件卡；`scripts/VisitorPortrait.gd` 改成按控件尺寸比例绘制，能放进主游戏的 216×253 肖像窗。

## 2. 下面还是那些文件

主游戏中间的卷宗区域现在是一个**文件夹**：

- 人情簿、院系账本、明日安排、感谢函、临时通行条都是 `DeskItem` 纸卡；
- 拖动、单击展开、点“收起”折回；
- 右侧“其他材料”架同步列出全部文件，点击也会展开对应纸卡；
- `F`/`C` 仍直接展开人情簿/院系账本。

文件来源、递交效果、消耗规则与 v1.17 相同（见 `V1.17-NOTES.md` 第 2 节）。

## 3. 访客：肖像 + 微信 + 左侧弹窗

- 来访者直接出现在主游戏的肖像窗口（216×253），姓名牌显示来访者姓名/角色。
- 主游戏的微信面板被复用为 **来访消息**：系统条 + 来访者陈述段落 + 来意，全部是微信气泡。
- 正式的“来访登记与拟办单”变成一个 **左侧弹窗**（700×737，位置 -12,78），只放字段、来意、随附文件、拟办行、经办人；**不再重复肖像和长陈述**，因为肖像在右、陈述在微信。
- 弹窗被移到左侧，右边缘到 688，微信从 689 开始，两者不互相遮住；主游戏肖像也完整可见。
- 回执同样在左侧；微信和肖像保持显示，点“下一位”后更新。

涉及：`scripts/ui/ChatPanel.gd` 增加 `set_header/clear_messages/add_message/add_system`；`scripts/Modals.gd` 增加 `compact` 模式；`scripts/Main.gd` 的 `_show_modal_left()`、`_show_visitor()`、`VisitorPortrait` 调用。

## 5. 测试

```powershell
python -X utf8 tools/project.py test --state allocationcheck --state savecheck --state backupcheck --state continuecheck --skip-shots
python -X utf8 tools/project.py test --skip-shots
python -X utf8 tools/project.py test --state shotregress
```

- `allocationcheck` 仍用真实鼠标点第一张项目卡（左键放/右键取）；
- `deskclick` → 文件卡展开/收起/拖动；
- `visitorclick` → 点左侧弹窗第一行 → `favor=2`；
- `visitoritemclick` → 点“人情簿”纸片再点第一行 → `favor=3 / perf=20`；
- `visitorpass` → 选“缓”生成 `pass_0_0`；
- `visitorconsume` → 感谢函递交后从 items 移除；
- `autoweek` 仍能在第 7 天结局。
