# v1.14 — 灯灭之前：精力/金钱分配、来访剧情与人情簿

这一版在每个工作日结束、下一天开始之前，加入一个可以实际操作的“灯灭之前”阶段：
把当天的**精力**和**金钱**硬币放进八个项目框，处理可能上门的来访者，然后才能进入下一天。
新增 **教务处主任、教导主任、同事、领导、辅导员、校外企业招聘人员、学生** 七类角色，
以及一套按角色分别记录的**人情**系统。人情不只来自分配，也来自盖章、行政待办、微信回复和夜班批示。

完整流程：

```text
第 N 天审查 → 下班单 → 夜班批示 → 灯灭之前（分配 + 来访） → 第 N+1 天通告 → …
```

第 7 天夜班后直接进入结局，不再分配。因此一局共有 **6 次**分配（第 1—6 天夜班之后）。

---

## 1. 精力 / 金钱

每晚从一份预算开始，两枚硬币分别代表：

| 硬币 | 说明 | 上限 |
|---|---|---|
| 精力 | 你还能坐下来做的事 | 7 枚 |
| 金钱 | 你能自己垫出去的钱 | 6 枚 |

基础预算按夜递减，越到周末越累；人情加成可以把预算补回来：

| 夜（第 N 天之后） | 精力 | 金钱 |
|---|---|---|
| 第 1 夜 | 5 | 4 |
| 第 2 夜 | 5 | 4 |
| 第 3 夜 | 4 | 4 |
| 第 4 夜 | 4 | 3 |
| 第 5 夜 | 4 | 3 |
| 第 6 夜 | 4 | 3 |

操作：

- 左键点项目框放入一枚该框需要的硬币；右键点项目框取回。
- 左上角两张大硬币只显示预算/剩余；v1.16 起不再需要选中硬币，左键永远放该框需要的硬币。
- “全部收回”把已放进框里的硬币退回托盘。
- **硬币放完**（不是每个框都排满）才能点“安排好了 · 进入第 N 天”，或按 `Enter`。
- 来访者消耗的硬币也从同一份预算里扣，所以“批”得多，项目就排得少。

## 2. 八个项目框

| # | 项目 | 硬币 | 上限 | 每枚收益 |
|---|---|---|---|---|
| 01 | 论文指导 | 精力 | 3 | 学生 +1 · 绩效 +¥25 |
| 02 | 教务材料 | 精力 | 2 | 吴敬之 +1 · 绩效 +¥20 |
| 03 | 课题申报 | 精力 | 1 | 郑国栋 +1 · 绩效 +¥60 |
| 04 | 合规检查 | 精力 | 1 | 郝立本 +1 · 绩效 +¥20 |
| 05 | 人情往来 | 金钱 | 2 | 林嘉树 +1 · 绩效 +¥10 |
| 06 | 学生资助 | 金钱 | 1 | 沈知夏 +1 · 学生 +1 · 绩效 +¥15 |
| 07 | 校企联络 | 金钱 | 1 | 许明辉 +1 · 绩效 +¥40 |
| 08 | 家用 | 金钱 | 2 | 排满 2 枚：声誉 +1 |

- 项目收益在点“安排好了”时统一结算；期间右侧“预计”会实时显示将获得的绩效、声誉和人情。
- “家用”是唯一不进人情簿的项目：它换的是声誉（最多恢复到 5），在声誉快见底时是一根保险绳。
- 每个框的容量合计正好等于上限（精力 7 / 金钱 6），所以加成再多也不会出现“硬币放不进去”。

## 3. 来访与批准

每次分配开始时，可能已经有人在门口等。来访发生在项目分配之前，先处理人，再排班。

| 夜 | 来访 | 角色 | 剧情由头 | 选项 |
|---|---|---|---|---|
| 第 1 夜 | 九点四十，辅导员来敲门 | 辅导员 沈知夏 | 学生母亲手术，请假条只有一天 | 批 / 驳 / 开临时通行条 |
| 第 2 夜 | 隔壁窗口的灯还亮着 | 同事 林嘉树 | 女儿发烧，请人顶答辩秘书 | 顶 / 不顶 / 一起找学生助理 |
| 第 2 夜 | 学生又回来了 | 学生 | 参考文献被退回，打印店已关门 | 按条例退回 / 现在帮他看 / 让他自己对照 |
| 第 3 夜 | 主任的茶杯放在桌角 | 教务处主任 吴敬之 | 评估组要看退回率，要求改三份材料 | 照办 / 一份不改 / 只改一份 |
| 第 4 夜 | 教导主任带着一份报告 | 教导主任 郝立本 | 42.6% 查重报告：立案还是申诉 | 立案 / 给申诉 / 交学术委员会 |
| 第 5 夜 | 副院长的电话打到座机上 | 领导 郑国栋 | 评估前要一本“规范化案例” | 接 / 推 / 拉同事一起 |
| 第 5 夜 | 企业的人在校门口等 | 校外企业招聘人员 许明辉 | 借窗口旁场地办宣讲，给劳务费 | 批 / 不借 / 只给海报位 |
| 第 6 夜 | 明天答辩的学生 | 学生 | 材料被退回，来不及重印 | 特事特办 / 按规矩 / 陪他去打印店 |
| 第 6 夜 | 主任来清“人情件” | 教务处主任 吴敬之 | 局里查“先受理后补”，要求清理 | 全部补正 / 只补有签字的 / 不动 |

- 每个选项都标了 `批 / 驳 / 缓`，但没有标准答案：
  批可能得罪制度，驳可能得罪人，缓通常两边都记你一点。
- 选项下面直接写出效果（谁的人情、绩效、声誉、精力/金钱），余额不够时按钮变灰并写明原因。
- 选择后会出现一张“已批 / 已驳 / 已缓”的回执，附结果文字和已入账的人情；点“下一位”或“去排班”。

## 4. 七个角色与人情

| 角色 | 姓名 | 门槛 | 人情加成 |
|---|---|---|---|
| 教务处主任 | 吴敬之 | 3 | 每周排班多 1 枚金钱 |
| 教学副院长（领导） | 郑国栋 | 3 | 每周排班多 1 枚金钱（项目经费） |
| 教导主任 | 郝立本 | 2 | 每次排班额外 +¥80（他替你压事） |
| 同事 | 林嘉树 | 3 | 每周排班多 1 枚精力（他替你顶班） |
| 辅导员 | 沈知夏 | 2 | 每周排班多 1 枚精力（她帮你跑学生） |
| 校外企业招聘人员 | 许明辉 | 3 | 每次排班额外 +¥120（企业劳务） |
| 学生 | 全体 | 6 | 每周排班多 1 枚精力（学生助理） |

- 人情 **0—10**，分五档：生疏 / 点头 / 熟络 / 交心 / 过命。
- 硬币加成在每次分配开始时读取；本夜新涨的人情从下一夜起生效。
  教导主任/企业招聘的固定绩效按**结算时**的人情计算，所以本夜排到门槛也能吃到。
- 按 `F` 打开**人情簿**：每个角色的分数、档位、加成是否达成、最近 5 条变动。
- 下班单会显示当天的人情净变化；结局会列出整周的人情簿，并按最高分写一句短评。
- 存档版本升到 **4**，人情、人情日志和分配日志进入每日快照；旧存档迁移后为空簿。

### 4.1 人情从哪里来

| 来源 | 变化 |
|---|---|
| 项目框 | 见第 2 节；在“安排好了”时结算 |
| 来访选择 | 见第 3 节；选项上直接标出 |
| 正确盖章 | 学生 +1 |
| 误判投诉 | 学生 −2、吴敬之 −1 |
| 行政待办 | 按 `kind` 区分：请假 → 沈知夏；奖学金/优毕 → 吴敬之/郑国栋；交换/实验室 → 林嘉树；实习 → 许明辉；见下表 |
| 微信回复 | “按清单核对” → 吴敬之 +1；“最担心哪项” → 学生 +1；“先放桌上” → 不变 |
| 夜班批示 | 每个选项单独配置：照章/如实类通常加吴敬之或郝立本；通融/压下类通常加学生或领导 |

行政待办的默认人情：

| 类型 | 批准 | 退回 |
|---|---|---|
| 请假 | 沈知夏 +2、学生 +1 | 沈知夏 −1、吴敬之 +1 |
| 奖学金 | 吴敬之 +2、学生 +1 | 吴敬之 +1、学生 −1 |
| 优秀毕业论文 | 郑国栋 +1、学生 +1 | 吴敬之 +1、学生 −1 |
| 交换生 | 吴敬之 +1、林嘉树 +1 | 吴敬之 +1 |
| 实验室 | 林嘉树 +2 | 林嘉树 +1 |
| 实习推荐 | 许明辉 +2、郑国栋 +1 | 许明辉 +1、学生 −1 |

注意：人情和“判得对不对”是两条线。批准一份该退回的材料，学生会记你，但绩效和声誉照扣；
退回一份该批准的材料，教务处记你，学生也会记你。分配阶段就是把这两条线放在一起做取舍。

## 5. 界面

- **地盘**：沿用桌面/HUD，分配层压在桌面之上、Toast 与弹窗之下；HUD 的设置、音效仍可点。
- **左侧**：940×650 的深绿排班板，八个纸卡项目框，轻微旋转，排满时盖一枚红色“已排”斜章。
- **右侧**：上方“今晚的家底”硬币托盘；中间“人情簿”七行速览（印章、姓名、角色、分数、档位、十格刻度、加成勾）；下方“安排好了”按钮和剩余提示。
- **硬币**：程序绘制的像素圆币，精力为红底“力”，金钱为金底“钱”；空位是虚线圆加“+”。
- **声音**：投币 drop、取回 pick、排满 select、结算 day；沿用现有 11 条合成音效。
- **来访卡**：没有复用学生立绘，改用“来访登记 + 角色印章”的纸质回执；名字、职务、办公室、来意、三个选项和效果预览都在一张卡上。
- **动效**：分配层淡入、排班板上浮；投币有金色圆环；排满与结算沿用印章/翻页手感。

## 8. 一局怎么排

- 前期优先“论文指导 + 人情往来”：学生和同事最容易先到 6/3，学生助理和顶班会多出精力。
- 辅导员在第一次来访后通常就到 2，之后每夜多 1 精力；把她当成稳定收益。
- 主任/领导的门槛是 3：教务材料、课题申报和他们的来访各 2 点，通常第 3 夜前后能吃到 +1 金钱。
- 教导主任/企业招聘的加成是每次排班的固定绩效，越早到门槛越划算。
- “家用”只在声誉 3 以下时排；否则把金钱留给项目。
- 来访的“缓”选项通常不是最优收益，但能避免一个人掉到 0；如果某人的加成本周还要用，先保他。
