# v1.23 — 来访登记回到纸质窗口，可拖动

v1.21 的大号“仿微信”面板取消。来访重新使用纸质来访登记窗口：没有深色微信头、没有头像气泡、没有“微信”字样；陈述、来意、拟办、附件、回执都在一张纸面上。

---

## 1. 纸面来访登记

- 窗口仍是 `741×274`，位置默认 `(389, 96)`，但外观改为：
  - 米色纸面、深色纸边、左侧红色装订线；
  - 顶部 `来访登记 / VISITOR`、姓名/角色/第 N 位、精力/金钱；
  - 右上红框“来 访 / 待 批”章；
  - 陈述是带红色左线的纸面段落，不再用头像一个气泡一个气泡；
  - 拟办行是纸面横条，不是深色聊天行；
  - 附件栏是纸面拖放条；
  - 回执/下一位也在同一纸面里。
- 没有访客时，原来的微信面板也替换成一张小的纸质“来访登记 / 暂无来访”卡，不再露出学生微信。

---

## 2. 窗口可拖动

- 顶部左侧有一个 `⋮` 拖动把手；按住标题栏/把手即可把整张来访登记纸拖到桌面任意位置。
- 拖动范围限制在窗口内（x 0–639，y 70–586），不会被拖出屏幕。
- 窗口移动后，来访材料 drag/drop 仍以窗口当前矩形为投放区；拖材料、× 取消、悬停后果卡都保持。
- 排班期间主游戏的学生档案卡/学生微信/中央卷宗/印章托盘全部隐藏，所以拖动窗口后露出来的是木桌，不是别人的档案。

---

## 3. 保留

- 选项 hover 的 320px 自定义后果卡（左侧，不挡选项；窗口靠左时自动改到右侧）。
- 材料拖进来提交、chip、右侧 × 取消。
- 回执、下一位/去排班。
- 主游戏原木桌上的材料外形（v1.22）。

---

## 4. 涉及

- `scripts/ui/VisitorChat.gd`：纸面重绘、纸面段落、纸面拟办/附件、顶部拖动把手与拖动逻辑；
- `scripts/AllocationView.gd`：删除 `ChatPanel` 访客聊天，改成纸质“来访登记/暂无来访”小卡；窗口显示/隐藏；
- `scripts/DeskView.gd`：排班时把 `official_card` / `chat_panel` 一并隐藏，拖动窗口不会露出学生档案；
- `tests/TestMain.gd`：新增 `visitordrag`（拖标题栏 → 位置从 389,96 到 489,196）。
