# v1.17 — 灯灭之前的桌子、道具文件与访客肖像

> **v1.18 已重排**：这一版的“上方排班板 + 下方新桌子”是过渡方案；v1.18 直接复用主游戏版式（规则书→项目书、学籍档案→排班档案、卷宗→文件、肖像/微信→来访者）。本页保留道具文件、随附文件、消耗/存档规则说明；`109–112` 为过渡截图。

这一版把“灯灭之前”从一张排班板改成一个**像主游戏一样的桌面场景**：上面是明日安排，下面是桌子；人情簿、院系账本、感谢函、临时通行条都变成桌上的道具文件，可以拖动、点开、收起。来访时可以从桌上挑一份文件递过去。

存档仍是 **v5**；`RunState.items` 是可选字段，旧档没有时自动补三份基础文件，不要求迁移。

## 1. 布局：上排班、下桌子

```text
┌ 明日安排（8 个项目，4×2） ────────────────────────────── 精力/金钱  全部收回 ┐
│  论文指导   教务材料   课题申报   合规检查                                  │
│  人情往来   学生资助   校企联络   家用                                      │
└──────────────────────────────────────────────────────────────────────────────┘
┌ 03 窗口的桌子 ──────────────────────────────────────────────── 排班收尾 ─┐
│  [人情簿] [院系账本] [明日安排] [感谢函] [临时通行条] …  已分配 / 预计   │
│  拖动 / 点开 / 收起                                          安排好了    │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 项目框改成 **4 列 × 2 行**，每框 306×180；左键放入、右键取回保持不变。
- 原来的右侧“硬币托盘 + 固定人情簿”整块移除；预算改为排班板右上角的 `精力 X · 金钱 Y`，全部收回也在同一行。
- 桌子的木纹、纸张和窗口拖动沿用主游戏的美术；底部提示：`左键放入 · 右键取回 · F 人情簿 · C 学院账本`。
- 收尾面板在桌子右侧：已分配/来访开销、预计绩效与人情、`安排好了 · 进入第 N 天`。

涉及：`scripts/AllocationView.gd`、`content/world.json` 的 `allocation.hint`。

## 2. 桌子上的道具文件

新增 `scripts/DeskItem.gd`：

- 收起状态：136×70 的纸卡，带类型角标、标题、来源、摘要（总人情/6 学部/8 项/第 N 天/一次性）。
- **拖动**：按住卡片或展开后的纸面移动；限制在桌子范围内，拖动时自动置顶。
- **展开**：单击卡片展开成 460×212 的纸张窗口；标题栏有“收起”按钮。
- **收起**：回到卡片，位置保留。
- 多份文件可以同时展开，后点的置顶；文件被消耗后卡片自动消失。

文件类型与来源：

| 文件 | 来源 | 展开内容 | 递交效果 |
|---|---|---|---|
| 人情簿 | 初始 | 7 位角色的人情值/档位 | 可复用 · 对方人情 +1 · 绩效 +¥20 |
| 院系账本 | 初始 | 6 个学部的导师/主任/规范通过 | 可复用 · 对方人情 +1 · 绩效 +¥20 |
| 明日安排 | 初始 | 8 个项目的投币进度 | 可复用 · 对方人情 +1 · 绩效 +¥20 |
| 感谢函 | 学部满 2 位规范通过 | 学部/导师/主任/学生/回礼 | 一次性 · 对方人情 +2 · 绩效 +¥40 |
| 临时通行条 | 来访选“缓” | 窗口/天数/用途 | 一次性 · 对方人情 +1 · 绩效 +¥20 |

- 感谢函在 `Main._college_pass()` 触发里程碑时写入 `run_state.items`；
- 临时通行条在来访选“缓”时写入；
- `RunState.items` 进入 `day_snapshot()` / `restore_day()`，跨天保留；
- 旧档没有 `items` 时，`ensure_base_items()` 补三份基础文件。

`F` / `C` 在灯灭之前不再打开全屏弹窗，而是展开桌上对应文件；审查阶段仍保留原来的全屏账本弹窗。

## 3. 来访：肖像 + 随附文件

- 新增 `scripts/VisitorPortrait.gd`：程序绘制的纸质占位肖像（相框、头发、脸、西装、领带、角色色条、角色印章）。不需要额外立绘资源，后续可直接替换成真实肖像。
- 来访单头部改成：**肖像 78×106 + 姓名/剩余 + 来访章**；姓名从 34px 调到 30px，给肖像让位。
- 新增“随附文件（可选）”区：
  - 桌上所有 `items` 以 150×34 的纸片列出；
  - 选中的纸片红框并显示“已附”；
  - 一次来访只能附一份；感谢函/通行条标注“一次性”，簿子/账本/日程标注“可复用”；
  - 消耗品优先展示，最多列 8 份，更多文件用“另有 N 份文件未列出（桌上可查看）”提示，避免来访单被撑爆。
- 递交后：
  - 在所选选项的效果上追加对方的 `+1` 人情（感谢函 `+2`）和 `+20`/`+40` 绩效；
  - 结果页多一行 `随附：《…》 · 已阅/已归档 · 对方人情 +N`；
  - 一次性文件从 `RunState.items` 移除，卡片从桌上消失；可复用文件保留。

涉及：`scripts/Modals.gd` 的 `_visitor_header`、`_visitor_items`、`visitor`、`visitor_result`；`scripts/Main.gd` 的 `visitor_item`、`_visitor_opt_with_item`、`_on_visitor_action`。

## 4. 输入的边界

- 桌子卡片用 `mouse_filter STOP`；卡片里的字全部 `IGNORE`，所以拖动/点击落在卡片本身。
- 展开后的“收起”按钮是唯一会拦截点击的子控件；点纸面只拖动，不会误收起。
- 拖动位移小于 4px 视为点击，展开卡片；大于 4px 只移动，不展开。
