# v1.20 — 去掉碍眼提示，换掉纸片人像

> **v1.21 追加**：来访登记弹窗已取消，陈述/选项/附件/回执都放进了加大的来访消息面板；本页的“左侧紧凑登记单”描述已被 v1.21 取代。

这一版只做减法和一个大替换：把灯灭之前界面上所有“教你怎么点”的常驻提示拿掉，并把程序绘制的来访者纸片人像换成主游戏已有的手绘肖像（做成来访登记照片）。

---

## 1. 去掉的提示

- **今晚流程面板整个删除**：左侧不再有“① 右上看微信 / ② 左上排项目 / ③ 档案卡收工 / 左键放 / 右键取 / F·C”等常驻说明。
- **主游戏的“今日队列”在排班时隐藏**：`DeskView.set_allocation_chrome(true)` 同时隐藏学生队列、印章托盘、裁决条、批注板，不再露出“拖入印章”；收工/中止排班时恢复。
- 项目书底部的“8 项 · 左键放 / 右键取”删除；
- 文件夹底部“拖动 / 点开 / 收起”删除；
- 材料架底部“F 人情簿 · C 学院账本”删除；
- 文件小卡上的“拖 · 点开”删除，只保留鼠标悬停 tooltip；
- 排班档案卡下方的“都已放好 / 还剩…”说明删除，只保留按钮与“已分配 7/9”；
- 底部横条改成只有“第 N 夜 · 灯灭之前”和“03 窗口 / WINDOW 03”；
- 来访登记单里“陈述见右侧微信……”“批/驳/缓没有标准答案”等说明删除；
- 来访结束 toast 只留“来访结束。”；
- 空来访 toast 只留“今晚没人来。”。

需要操作说明时，README / WALKTHROUGH / 帮助里仍有；游戏画面上不再一直挂着。

---

## 2. 来访者人像

- 不再画纸片人。`VisitorPortrait` 复用 `assets/portraits/` 里已有的手绘学生肖像，裁成 186×204 的**登记照片**：
  - 纸相框 + 内框 + 四角相册固定角；
  - 暖色照片调 + 边缘压暗；
  - 左下红框“来访”章；右下角色小印；
  - 底部 `VISITOR / 03` 编号；
  - 姓名/职务仍由右侧名牌显示。
- 角色到肖像的固定映射：
  - 教务主任 `d4s4`、教学副院长 `d3s2`、教导主任 `d3s4`、
  - 同事 `d2s4`、辅导员 `d2s3`、招聘 `d4s1`、学生 `d5s3`。
- 没有访客时不再出现纸片人，只留**空相框 + “等待来访”**与“暂无来访”名牌。

这样它和主游戏的学生肖像同属一套画风，但通过照片调、相框、来访章和角色印区分成“来访登记照”，不会像是把当前学生直接搬过来。

---

## 3. 来访单

- 左侧 compact 登记单的内容放进 `ScrollContainer`，高度压到 470，**底部不再留一大块空白**；字段、来意、随附文件、拟办行、经办人仍然完整。
- 回执仍是短卡，不再重复肖像和陈述。
